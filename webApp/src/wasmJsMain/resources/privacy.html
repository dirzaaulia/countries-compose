Privacy Policy

Effective Date: October 11, 2026

Welcome to Countries Compose, developed by Dirza Aulia (dirzaaulia.com).

1. Zero Personal Data Collection

We prioritize user privacy. Countries Compose does NOT collect, store, transmit, or share any personally identifiable information (PII).

  • No User Accounts: You do not need to register or log in.
  • No Analytics Tracking: We do not track user behavior or build user profiles.
  • No Targeted Ads: We do not collect advertising identifiers (AD_ID).

2. Open Scientific Data APIs

To provide real-time 3D planetary telemetry, weather forecasts, seismic monitoring, and macroeconomic statistics, Countries Compose connects directly to open scientific data providers:

  • REST Countries API (restcountries.com)
  • Open-Meteo Meteorology (open-meteo.com)
  • USGS Earthquake Hazards (earthquake.usgs.gov)
  • NASA EONET Crisis Tracker (eonet.gsfc.nasa.gov)
  • NOAA Space Weather (swpc.noaa.gov)
  • World Bank Open Data (data.worldbank.org)
  • CelesTrak / N2YO (celestrak.org)
  • FlagCDN Vector Graphics (flagcdn.com)

3. Local In-Memory Cache

Session data (such as weather forecasts and country details) is stored temporarily in your device's local memory to reduce bandwidth. This cache is cleared when the application closes.
